# DTS 201: Introduction to Data Science

This repository contains lab exercises, data cleaning tasks, statistical analyses, and check-in notes completed as part of the **DTS 201: Introduction to Data Science** course.

## 📂 Structure
* **Class 1:** Data inspection, handling missing values, managing DataFrames/Series, and exporting data structures to JSON.
* **Class 2:** Statistical calculations on datasets (mean, median, min, max, and variance analysis) using Python and the built-in `statistics` module.
* **Check-in Notes:** Theoretical summaries covering data science definitions, the seven stages of the data science lifecycle, and real-world sector applications.

## 🛠️ Tech Stack
* **Language:** Python
* **Environment:** Jupyter Notebook in VS Code
* **Libraries:** `pandas`, `statistics`
